## Lecture Sequence

1. Python Basics  
   Introduction to Python fundamentals, syntax, control flow, functions, and working with data in a scientific programming context.

2. Introduction to NumPy  
   Core array operations, vectorized computation, broadcasting, and efficient numerical workflows using NumPy.

3. Computation on NumPy Arrays  
   Advanced array computations, indexing, masking, aggregation, and performance-oriented numerical techniques.

4. Intro to Pandas  
   Working with tabular data, Series/DataFrames, indexing, filtering, and common data manipulation patterns.

5. Pandas Grouping Data  
   GroupBy operations, aggregation, reshaping, and summarizing data across categories and time periods.

6. Pandas Strings and Time Series  
   Text cleaning, string methods, time parsing, date indexing, and time-based data analysis.

7. Matplotlib and Seaborn  
   Creating effective visualizations, plotting patterns, and statistical graphics for exploratory data analysis.

8. Intro to ML  
   Overview of machine learning concepts, supervised learning, model training, and evaluation basics.

9. Hyperparameters and Model Validation  
   Tuning model parameters, validation strategies, cross-validation, and avoiding overfitting.

10. Feature Engineering, Embedding  
   Transforming raw data into predictive features, encoding categorical data, and working with embeddings.

11. In-depth: Naive Bayes, Decision Trees, SVM  
   A closer look at classical classification algorithms, their assumptions, strengths, and practical use.

12. PCA, Clustering, Manifold  
   Dimensionality reduction, clustering techniques, and manifold learning for uncovering structure in data.

X. Web Scraping for ML  
   Collecting data from the web, cleaning it into usable datasets, and preparing it for machine learning workflows.
